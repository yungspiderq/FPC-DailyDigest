# 🌅 DailyDigest — Утренний дайджест

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

Каждое утро в заданное время присылает одну сводку со всей картиной магазина —
вместо десятка разрозненных уведомлений.

## Что в сводке

```
🌅 Утренняя сводка (16.10.2026)

💰 Продажи за вчера (15.10):
   12 заказ(ов) на 3 450 ₽
   Позавчера: 10 на 2 900 ₽ (📈 +19%)
↩️ Возвраты за вчера: 0

📋 Активные заказы: 3
   Старейший ждёт подтверждения: 5 ч. 20 мин.

📦 Остатки товаров (файлов: 8):
   🚨 Пустые: 1 | ⚠️ Ниже 5 шт.: 2

💳 Баланс: 12 450 ₽ (к выводу: 10 000)

Хорошего дня и побольше продаж! 🍀
```

## Возможности

- 💰 **Продажи за вчера**: количество, сумма, возвраты + сравнение с позавчерашним
  днём и тренд (📈 +19% / 📉 −12%).
- 📋 **Активные заказы**: сколько ждут подтверждения и сколько висит старейший.
- 📦 **Остатки**: сколько товарных файлов пустые и сколько ниже порога.
- 💳 **Баланс** аккаунта (₽ / $ / € — что есть).
- 🕐 Время отправки настраивается (по часам сервера); границы «вчера» — по
  московскому времени FunPay.
- 🔄 Кнопка **«Отправить сейчас»** — получить сводку в любой момент.
- Ровно одна отправка в день (состояние переживает рестарт Кардинала).
- Умная пагинация истории: старые страницы не запрашиваются (ранняя остановка).

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-DailyDigest/main/daily_digest.py -O plugins/daily_digest.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/digest`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🔄 Отправить сейчас | Прислать сводку немедленно |
| 🟢/🔴 Дайджест: ВКЛ/ВЫКЛ | Включить/выключить ежедневную отправку |
| 🕐 Время: 09:00 | Когда присылать сводку (по часам сервера) |
| ⚠️ Порог остатков: 5 | Какой остаток считать «низким» в сводке |

## Важно знать

- Время отправки — **по часам сервера** (`date` в консоли); даты заказов FunPay —
  по Москве (UTC+3), плагин это учитывает при расчёте «вчера».
- Если Кардинал был выключен в момент времени X и запустился позже — сводка за
  сегодня всё равно придёт сразу после запуска (один раз).
- Возвраты считаются отдельно и не входят в сумму продаж.
- Дайджест отправляется как уведомление типа «Прочие уведомления (плагины)».
- Настройки: `storage/plugins/daily_digest/settings.json`.

## Состав репозитория

  тренды, возвраты, активные заказы, остатки, баланс, ранняя остановка пагинации,
  весь Telegram-UI). Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_daily_digest.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_daily_digest.py
  ```
